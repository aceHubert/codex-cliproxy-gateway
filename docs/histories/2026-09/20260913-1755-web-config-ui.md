### 🧠 Design Intent (Why)
Web UI 定位为网关内建基础能力而非独立服务（区别于 ccr 的独立 Next.js UI）：零配置、零新增进程、生命周期完全跟随网关，因此不新增任何 config.json 字段、schema 零变更。UI 内嵌在 `/ui` 路径由现有 launchd 进程服务，既保住单文件发布物，又天然获得与 CLI 完全一致的写路径（审计 + pendingRestart + kickstart 重启）。React 仅是构建期 devDependency，运行时只是内联进 HTML 的静态产物。安全上以「loopback + token + Host/Origin 白名单」三重边界替代配置开关——不运行网关即无 UI。
