### 🧠 Design Intent (Why)
两个日志文本区是同一种「查看文件尾部」的组件，查找交互必须完全一致：同一组件、同一位置（文本区右上浮动）、同一快捷键、同一范围语义（当前文件，绝不命中页面其他部分）。React 版用渲染期字符串分片 + 全局命中编号实现高亮（闭包固化编号避免 ref 回调时序陷阱），比原型的 DOM TreeWalker 更贴 React 心智且天然与内容刷新同步；捕获层兜底保证任何焦点位置下 Cmd/Ctrl+F 都不会漏成浏览器原生全页查找。
