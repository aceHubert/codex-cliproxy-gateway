# 网关与插件配置字段归属收敛

## 目标

网关声明且判断插件启用开关，AgentConfig 仅声明公共参数与任意字段索引，各插件通过模块增强声明自身使用的专属参数；移除重复声明、过时配置字段和配置视图。

## 范围

- 包含：配置接口、五插件装配与开关判断、校验调用、遗留 prefix 清理、发布类型及回归测试。
- 不包含：并行中的协议转换重构、配置文件结构变更、旧配置读取迁移行为变更。

## 背景

- 相关文档：docs/plugin-contract.md。
- 配置文件与运行时规范仍由网关拥有，各插件不得反向依赖网关。
- 工作区已有大量未提交修改；仅基于修改前快照统计本任务增量。

## 风险

- 字符串索引会扩大 keyof，不能再用 Omit 按字面字段筛选配置；默认配置直接满足 GatewayConfig。
- 开关判断移到网关后，直接创建插件即启用；关闭开关的测试必须验证网关不装配插件。
- 保留环回监听、账号参数校验及显式 false；纯类型导入不应计作核心运行时依赖。

## 里程碑

1. 明确公共、网关与插件专属字段。
2. 清理声明、注入、启用逻辑与过时 prefix 校验。
3. 验证边界、构建、类型与回归测试，记录交付结果。

## 验证方式

- bun run check。
- 新增配置字段归属及发布类型消费方测试，确保任意字段索引不削弱已声明字段的类型。
- 复查五插件无网关开关消费、公共接口无插件专属声明、网关无重复或过时字段。
