# ZCode 3.18.0 接入适配

## 目标

网关读取升级后的客户端凭据，按 3.18.0 桌面协议签发个人和团队项目令牌并转发请求。

## 范围

- 包含凭据 v2、项目 JWT 签名、团队短令牌、端点映射和 Start Plan 正文。
- 保持配置的原子写入和隔离边界，凭据只在内存使用。

## 背景

- 协议依据为本机 3.18.0.10300 安装包。
- 既有工作区包含其他未提交改动，各任务限定文件和修改区域。

## 风险

- 系统凭据存储可能需要操作系统授权，遵守正常权限流程。
- 服务端策略无法由离线样例证明，以模拟上游验证协议并明确实网验证范围。

## 里程碑

1. 完成凭据读取和签名适配。
2. 完成团队令牌及正文、映射接线。
3. 完成回归、检查及历史记录。

## 验证方式

- 专项测试覆盖凭据格式、签名和短令牌续期。
- 执行 bun run check。
- 本机只读验证凭据和目录，输出仅含状态和计数。
