# ZCode 当前 provider 的 Anthropic 直通入口

## 目标

为 Claude Code 增加默认关闭的 `/zai` 入口，随 ZCode 当前选择读取 Coding Plan、体验套餐或 API Key 的 Anthropic 配置，保持模型、正文与响应事件原样传输。

## 范围

- 包含：独立 `src/zai.ts`、HTTP/升级路由隔离、本地认证、配置类型与 Schema、模拟上游测试、使用文档。
- 不包含：客户端签名、握手、PoW、OAuth/key 兑换、模型目录改动、生产 API 联调、用户运行配置修改、提交或发布。

## 背景

- 相关文档：`docs/PLANS_GUIDE.md`、`docs/HISTORY_GUIDE.md`、[Z.AI Claude Code 接入说明](https://docs.z.ai/devpack/tool/claude)。
- 相关代码路径：`src/gateway.ts`、`src/cli.ts`、`src/types.ts`、`schemas/gateway-config.schema.json`。
- 已知约束：接替任务从已有 working-tree 状态隔离复制；继承的未提交变更不能回滚，也不能计入本次统计。
- Git 基线：`deac0cdcb77a67276b0cf82b966678e6749ad086`，启动时 detached HEAD；修改前已在仓库外保存完整 tracked/untracked 文件快照与 Git 状态。

## 风险

- 风险：误路由可能泄露本地凭证；ZCode 切换配置时可能选错账户；日志或流复制可能暴露凭据或破坏取消。
- 缓解方式：最先处理 `/zai` 路由；精确 provider 选择且不回退账户；仅环回与独立 token；官方 HTTPS Anthropic 基址；请求头白名单；禁止重定向；该入口不进入完整交换日志。
- 风险：套餐可能要求 ZCode 专属签名，模拟通过不能代表真实可用。
- 缓解方式：三种模式均明确标记未生产实测；不把上游 401/403 统一归为签名错误。
