# AGY 思考级别与模型还原重写

## 目标

根据最新官方 CLI 和文档，将客户端思考级别与上游模型调用抽象为可还原的统一描述；目录展示和请求发送使用同一份模型能力，不靠重复映射或临近档位回退。

## 范围

- 包含：AGY 档位定义、模型家族与默认变体、请求解析、目录缓存、回归测试及文档。
- 不包含：真实推理、凭据存储、安装/服务重启、其他插件协议。

## 背景

- 相关文档：官方 `/docs/cli/commands/effort/`、`/docs/models`、`/docs/enterprise`；仓库上游调研及历史记录。
- 相关代码：`packages/agy/src/{catalog,index,request}.ts`。
- 约束：保留已有未提交改动；精确匹配档位，显式模型 ID 可直连，未知或不支持的 effort 不降档。

## 风险

- 风险：将变体后缀误当作所有模型的传输方式；缓存缺失能力导致还原错误。
- 缓解：使用显式模型选择结果描述上游 ID 与思考配置；覆盖家族、显式成员、固定模型、未知目录与缓存重载。

## 里程碑

1. 核查最新官方资料和本机 CLI。
2. 实现统一定义、能力提取与请求还原。
3. 定向回归、完整检查、独立审查与历史记录。

## 验证方式

- 命令：AGY 定向测试、`bun run check`；测试限制 60 秒。
- 手工检查：目录支持档位与发送的真实模型 ID 一一对应，无 xhigh/max 降档。
- 观测检查：只读 CLI 版本/目录，不进行真实推理。

## 决策记录

- 2026-11-16：官方明确 low/medium/high/xhigh/max 是模型相关的选择；固定模型不能从全局枚举推断可调能力。Hydrogen 默认 high，Claude 5.5 企业变体默认 medium；默认值必须按目录选择而非全局硬编码。
- 2026-11-16：从官方协议描述符确认 groupedModels→ModelVariantList→SupportedThinkingLevel 才是选择器分组；tieredModelIds→TieredModelConfig 是 flash_lite/flash/pro 性能系列，禁止混同。还原 ID 必须经实际目录校验，旧目录没有 groupedModels 才按后缀分组。
- 2026-11-16：统一模型能力分为 fixed、parameter、variants；转换层消费 `{model, thinkingLevel?}`，不再猜测名字后缀。能力、默认档位和重定向随缓存一起哈希、校验及重载，缓存修订为 11，测试拒绝旧 v10 描述。
- 2026-11-16：按用户要求将档位类型、能力和还原函数合并到 catalog.ts，移除新建的 tiers.ts；消费者直接从定义文件导入。
- 2026-11-16：移除无可调思考级别模型的默认 medium 占位值，只在实际存在支持级别时声明默认值；缓存修订升为 12，防止复用旧 v11 的占位结果。
