
# 迁移目录

## 目标

将旧默认安装的目录复制从硬编码受管白名单改为整个目录树，保留旧目录、目标已有内容和原权限；安装失败时只撤销本次迁移实际新增或修改的条目。完成后保留未提交变更，等待用户验收。

## 范围

- 包含：`default-install-migration.ts`、迁移测试、使用说明、仓库约束和技术债更新。
- 不包含：真实本机安装迁移、真实凭据读取、插件转换协议、llm-bridge 计划、提交或发布。

## 背景

- 相关文档：[插件产物边界计划](gateway-plugin-artifact-boundary.md)、[技术债追踪](../tech-debt-tracker.md)、[迁移指引](../../monorepo-migration.md)。
- 相关代码路径：`apps/gateway/src/default-install-migration.ts`、`test/default-install-migration.test.ts`。
- 既有约束：只由 install 触发默认目录迁移；环境覆盖、显式实例、自定义地址、配置补缺、归属校验及服务恢复保持原行为。

## 风险

- 整目录包含用户自建文件与临时文件：只复制缺失条目，保留旧目录，不清理或解析额外文件。
- 同名目录递归合并可能改变用户选择：按已确认方案 A，目标存在时整体跳过，包括文件、目录及悬空链接。
- 链接可能指向目录外：复制过程使用 lstat，静默跳过源符号链接；配置、状态及凭据仍遵守既有常规文件校验。
- 源根目录也可能是链接：准备阶段在读取配置、状态前跳过链接根；应用阶段重新校验源根为真实目录，拒绝准备后被替换为链接的情况。
- 凭据不能混入普通复制：顶层 `credentials.json` 排除，继续通过 `createApiKeyStore` 平台分派迁移。
- 回滚误删后续生成文件：移除按文件名扫描清理，采用本次新增文件、目录及修改前快照；只删除清单内文件与已空的新增目录。
- 只读根目录或子目录无法写入副本：复制期间临时保留所有者写入权限，完成后恢复源权限；回滚期间同样临时开放，保留下来的非空目录恢复原权限。

## 里程碑

1. 建立计划，确认已有变更与方案 A 的冲突语义。
2. 移除白名单，实施整目录复制、链接跳过和清单回滚，补充行为测试。
3. 运行完整检查，更新技术债与历史记录，归档计划，不提交。

## 验证方式

- 命令：迁移专项测试（60 秒上限）、`bun run check`、`git diff --check`。
- 手工检查：复制范围、同名目录整体跳过、权限、凭据隔离、失败恢复及旧目录完整性。
- 观测检查：仅使用临时测试目录和虚构凭据；用户已完成本机迁移，本次不重跑。
