# AGY 原生搜索适配

## 目标

AGY 模型触发搜索时由 AGY 执行原生搜索，并把结果还原为 Codex 可消费的工具响应；不再误送 CLIProxy 或 ChatGPT。

## 范围

- 包含：搜索协议取证、可选插件搜索契约、公共 alpha/search 分发、AGY 搜索执行及结果转换、测试和文档。
- 不包含：其他插件原生搜索实现、修改系统代理/信任、自动部署和服务重启。

## 背景

- 相关文档：`docs/agy-native-search-research.md`。
- 相关代码：plugin-api 的类型/注册表、gateway 搜索入口、AGY 目录和传输。
- 约束：保留已暂存改动；令牌和请求头不写调试产物；只用公开查询做最小验证。

## 风险

- 风险：静态协议推断错误、搜索响应形状不兼容、命令未明确支持时伪造结果。
- 缓解：先核对真实请求与响应；捕获仅保存脱敏结构；限定支持范围并明确错误，不静默切换模型供应商。

## 里程碑

1. 取证 AGY 原生搜索与客户端结果协议。
2. 并行实现公共分发与 AGY 执行器。
3. 定向测试、完整检查、独立审查与交付。

## 验证方式

- 命令：定向测试及 `bun run check`，测试进程限制 60 秒。
- 手工检查：两种路由模式均不将本地搜索模型泄漏到默认上游。
- 观测检查：受控公共查询验证 Google 搜索和来源；不改生产配置或重启服务。
